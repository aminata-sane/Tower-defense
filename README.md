# 🏰 Kingdom Defense - Projet Tower Defense en C++

Bienvenue dans **Kingdom Defense**, un jeu Tower Defense en C++ d'inspiration médiévale !  
Développé dans le cadre d’un projet en trinôme pour apprendre la conception de jeu en C++ avec une bibliothèque graphique (SFML).

---

## 🎯 Objectif du projet

Créer un jeu où le joueur place des tours stratégiquement afin de défendre son royaume contre des vagues d’ennemis.

## 🗂️ Arborescence du projet

```bash
KingdomDefense/
├── assets/                  # Images, sons, sprites
├── src/                     # Code source principal
│   ├── main.cpp             # Point d’entrée
│   ├── game.cpp/h           # Boucle de jeu
│   ├── tower.cpp/h          # Gestion des tours
│   ├── enemy.cpp/h          # Ennemis
│   ├── map.cpp/h            # Carte et placement
│   ├── projectile.cpp/h     # Projectiles
│   └── ui.cpp/h             # Interface utilisateur
├── include/                 # Fichiers d’en-tête partagés
├── build/                   # Fichiers générés (CMake)
